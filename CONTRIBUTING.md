# Contributing

Thank you for helping improve WordPress SEO Theme Auditor.

## Before submitting a change

- Read `SKILL.md` and keep new guidance consistent with its evidence-first, regression-safe approach.
- Prefer precise, actionable instructions over broad SEO rules that can create false positives.
- Distinguish theme responsibilities from WordPress core, plugins, hosting, DNS, CDN, and server configuration.
- Use current official documentation when behavior may have changed.
- Do not add claims that a tool, test, or fix was executed unless it was actually verified.
- Keep code examples safe, minimal, and compatible with supported WordPress patterns.
- Use English for documentation and code comments.

## Pull requests

Please include:

1. The problem or use case addressed.
2. The proposed change and why it is correct.
3. Any relevant official references.
4. Potential compatibility or regression risks.
5. How the guidance was validated.

Keep pull requests focused. Avoid unrelated rewrites that make the skill harder to review.

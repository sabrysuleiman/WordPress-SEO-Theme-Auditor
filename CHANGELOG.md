# Changelog

Notable changes to this project are documented here.

## 1.1.0 - 2026-10-29

- Published as an npm package with an executable CLI (`npx wp-seo-theme-auditor`).
- Added `install`, `print`, `path`, and `info` commands, with `--dir`, `--local`, `--force`, and `--dry-run` options.
- No changes to the skill instructions themselves.

## 1.0.0 - 2026-10-28

- Initial public release of WordPress SEO Theme Auditor.
- Added a structured workflow for auditing, diagnosing, prioritizing, fixing, and verifying WordPress theme SEO issues.
- Covered classic, block, and hybrid themes; SEO-plugin integration; multilingual behavior; performance; accessibility; security; and regression checks.
- Added contribution guidelines, security policy, issue templates, and MIT license.

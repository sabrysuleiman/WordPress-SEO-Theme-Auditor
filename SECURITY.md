# Security Policy

## Reporting a vulnerability

Please do not publish credentials, private URLs, customer data, or an exploitable vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer privately through a verified contact method listed on the maintainer's GitHub profile.

Include a clear description, impact, reproduction steps, and any safe mitigation you can share. Do not include live secrets or personal data.

## Scope

This repository contains AI instructions and documentation, not a runnable WordPress plugin or service. Security reports are still welcome for unsafe code examples, instructions that could expose secrets or damage a site, and repository supply-chain concerns.
